# The Time World Map

An offline interactive 3D globe featuring China's geography, real-time day-night visualization, customizable time simulation, and the 24 Chinese solar terms.

一款在本机运行的交互式三维地球：从中国出发，看山河地貌，也看晨光与暮色如何流过整颗星球。

## 直接离线使用

1. 下载整个仓库 ZIP，解压。
2. 双击 **dist/index.html**。不需要 Node.js、HTTP 服务器或网络。
3. 使用支持 WebGL 2 的现代桌面浏览器。启用硬件加速；极旧的显卡或浏览器可能不支持。

发布 HTML 约 8.6 MB，包含全部代码、纹理及矢量数据。页面不会加载远程字体、CDN、API 或瓦片。文档中的来源链接仅在主动点击时联网。

## 功能

- Three.js 真正的三维球体，拖动旋转、滚轮缩放、平滑中国视角复位。
- 基于实际高程的 Natural Earth 地形晕渲，34 个省级行政区研究边界、10 个真实城市行政区域、河湖图层及地名。
- 城市：北京、上海、广州、深圳、杭州、南京、武汉、成都、重庆、西安。城市图层使用真实 OSM 行政关系多边形，不以点/圆替代。
- GPU 昼夜着色，默认 40% 夜幕浓度；几何晨昏线 / 标准视日出日落两种定义。
- UTC+8 实时、自定义日期时间、全天连续播放、暂停、拖动时间轴；30 / 60 / 120 秒播放一天。
- 按太阳视黄经求解 24 节气，支持 1900–2100 年；定位节气时刻或播放其北京时间自然日。
- 深色桌面优先界面和移动布局。

## 操作

“此刻”恢复系统时间；改变日期或时间进入手动模式。播放从当前进度继续，“↺”从 00:00 重新播放，自动停在同一天 23:59。选择节气后显示该节气的发生时刻，所有 UI 时间均采用固定 UTC+8，不受电脑所在时区或夏令时影响。

地图边界、城市范围、河湖与地名可分别切换。夜幕下地图仍可辨认。自然地貌标签是说明性标签，不是地貌范围边界。

## 地图数据与限制（请先阅读）

本项目是开放数据探索工具，**不是经中国地图审核的标准地图**。不能将界面中的边界表达当作法律、行政或测绘依据。未宣称已满足公开地图审核要求，也未手工添加或伪造争议边界线。发布或用于公众展示前，应按适用地区的规定自行评估和完成必要审核。

省界是 2019 年的低分辨率开放研究数据，不足以用于街道级观察，可能遗漏小岛、海域界线和近期行政变更；台湾、香港、澳门等边界表达也须结合来源限制理解。城市数据为 2026-10-28 OSM 快照，其质量与完整性不保证等同官方边界。省界与城市界年代、精度不同，可能存在重叠或微小错位。用户要求的“完整国界与全部必要海岛”不能仅凭这些开放数据保证，明确列为已知限制。

详细来源、版本、许可证、处理方式和精度见 [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md)。© OpenStreetMap contributors。城市数据库遵循 ODbL 1.0；应用代码 MIT，不代表全部数据 MIT。

## 开发

Node.js 22+：

```sh
npm ci
npm run dev
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
```

构建使用 Vite + vite-plugin-singlefile，把源码模块和资产内嵌为一个 HTML。开发可以联网安装依赖；发布程序不联网。不要手工修改 dist 文件，修改 src 后重新构建。

## 工程结构

- src/main.ts：交互、Three.js、Shader、图层和标注。
- src/astronomy.ts：太阳位置、节气、日照数学。
- src/time.ts：固定 UTC+8 日期与播放逻辑。
- src/geo.ts：球面坐标和说明性地名。
- assets/：可离线分发的数据与纹理。
- tests/：数学与独立天文基准测试。
- scripts/e2e.mjs：file:// 下禁用外部 HTTP(S) 的浏览器交互、截图验证。
- docs/：数据来源、天文定义、验证与已知限制。

## 验证

`npm test` 覆盖坐标、太阳位置、极昼极夜、UTC+8 跨日、闰年、节气和播放终点。2026 年 12 个主要节气时刻与香港天文台年历独立对照，容差 2 分钟，非以自家算法输出作为唯一真值。

GitHub Actions 构建后，在 Chromium 中直接打开 file:// 发布文件，拦截所有 HTTP(S) 请求，操作日期/节气/播放/图层/对话框并输出桌面、夜晚、冬至和手机截图。查看 PR 的 **Verify offline globe** 工作流及 `offline-globe-and-qa` 产物。真实设备 60 FPS 目标取决于 GPU、屏幕分辨率和浏览器；并非所有设备上的性能保证。

## 天文精度与范围

见 [docs/ASTRONOMY.md](docs/ASTRONOMY.md)。太阳位置考虑真实日期变化，不使用固定经线替代晨昏线。秒级显示不代表已证明秒级绝对精度。无天气、云层、局部地形遮挡、大气状态或个人位置采集。
